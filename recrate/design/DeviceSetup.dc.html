Existing rekordbox library
  • The drive has one shared library, so adding playlists means rewriting it. rekordbox’s 3 playlists, 137 tracks and their cues are carried over unchanged, and Recrate never removes them.
  • Before every export, each library and analysis file Recrate will change is backed up. Afterwards the new library is read back and compared. If anything of rekordbox’s is missing or different, the export is marked failed and the backup is put back.
  • If the drive is unplugged while its library is being written, it needs recovery. Recrate can only restore the backup once the drive is connected again, and shows the drive as needing recovery until then.
  • Recrate only writes library versions it recognizes. If a future rekordbox changes the format, Recrate won’t write to the drive until it supports that version.
  • Recrate’s playlists are marked as Recrate’s, so Export only lists and removes those. The marker is a convenience, not what keeps rekordbox’s data safe.
  • If rekordbox exports to this drive later, it may rewrite the library. Export from Recrate again afterwards.
The next export deletes the rekordbox playlists and their 137 tracks from KINGSTON, after backing up the drive’s library. rekordbox keeps its own copy on your computer.
